# Dice Game (game jam)

Godot 4.7.2, GDScript, 2D. Main scene: `res://scenes/main.tscn`.

- Godot binary: `/home/nelt1/Downloads/Godot_v4.7.2-stable_linux.x86_64` (not on PATH)
- Check for script/scene errors: `<godot> --headless --path . --quit-after 60`
- Re-import assets: `<godot> --headless --path . --import`
- The `godot` MCP server (`.mcp.json`) can launch the editor, run the project and read debug output.
- Layout: `scenes/`, `scripts/`, `assets/`. Use tabs and static typing in GDScript.
